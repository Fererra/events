# Документація

- `architecture.md` — модулі, шари та правила залежностей.
- `api-errors.md` — уніфікований формат помилок API.
- `api-auth.md` — ендпоінти автентифікації, токени, guards.
- `api-venues.md` — ендпоінти керування локаціями.
- `api-events.md` — події, переходи статусів та життєвий цикл.
- `api-tickets.md` — типи квитків, ліміти та залишок.
- `api-registrations.md` — атомарна реєстрація на події, перелік власних реєстрацій і скасування.
- `api-analytics.md` — збір статистики та ендпоінт аналітики.
- `requirements-traceability.md` — матриця трасування вимог і покриття тестами.
- `test-plan.md` — тест-план, стратегія тестування та каталог тест-кейсів (ES-36).
- `load-testing.md` — методика та результати навантажувального тестування `k6` при 50+ RPS (ES-41, N2).
- `ui-compatibility-report.md` — кросбраузерна/адаптивна перевірка Playwright і аудит Lighthouse (ES-42, N3/N6/N7).
- `regression-report.md` — передрелізний звіт регресійного тестування та реєстр дефектів `BUG-01`…`BUG-08` (ES-43).
